Cómo usar la API

Rápido, sin autenticación y pensado para integrarse en scripts o aplicaciones. A continuación verás los endpoints principales, parámetros útiles y ejemplos listos para copiar.

Base URL

https://{tu-dominio}

Ejecuta `fetch('/shares')` desde la misma web o usa la URL completa desde otros servicios.

Actualización

Los datos se actualizan periódicamente (aprox. cada 10 minutos). Para forzar una recarga cuando esté desplegada en una plataforma sin proceso en background, programá una llamada al endpoint de refresh desde un cron externo.

GET
/shares

Devuelve la lista completa de instrumentos y una sección meta con conteo y timestamp de última actualización.

Parámetros opcionales: q (busqueda), limit (cantidad).

Ejemplo
curl -s https://{tu-dominio}/shares | jq '.'
GET
/shares/{ticker}

Devuelve la cotización y datos históricos limitados del instrumento identificado por `ticker` o nombre.

Ejemplo: /shares/GGAL

fetch('/shares/GGAL').then(r=>r.json()).then(j=>console.log(j))

Ejemplo de respuesta

{
  "items": [
    { "ticker": "GGAL", "nombre": "Grupo Galicia", "cotizacion": 123.45, "variacion": 1.23, "precio_apertura": 122.0, "baja": 120.5, "alta": 125.0, "volumen": 123456 }
  ],
  "meta": { "totalCount": 123, "last_updated": "2026-09-21T12:34:56Z" }
}

Campos frecuentes: ticker, nombre, cotizacion, variacion, precio_apertura, baja, alta, volumen. Puede haber más campos según el origen.

Buenas prácticas y límites

  • Cacheá respuestas cuando sea posible; los datos se actualizan cada ~10 minutos.
  • Si despliegas en una plataforma sin proceso de fondo, programa un job externo que llame a /shares/refresh cada 10 minutos.
  • Los endpoints no requieren autenticación; si necesitas un SLA, considera desplegar en Render/Heroku/Cloud Run.
